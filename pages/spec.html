創作者平台 功能規格清單

（MVP + 拍賣核心版本）

前台（19）API（14）後台（27）

前台（Web）

1. 平台首頁 / Landing Page

功能說明：平台入口頁，未登入顯示平台介紹與精選內容，已登入切換為個人追蹤動態流。

  • 平台主視覺、精選創作者輪播
  • 熱門 / 推薦貼文、進行中拍賣區塊
  • 搜尋入口（創作者、hashtag、商品、拍賣）
  • 登入 / 註冊入口

2. 登入頁

功能說明：會員登入入口，支援帳密與第三方登入，啟用雙重驗證者須二階段驗證。

  • Email + 密碼登入
  • 第三方登入：Google / LINE
  • 登入錯誤提示（連續失敗 N 次鎖定帳號，需重設密碼或由客服解鎖）
  • 已啟用雙重驗證會員：登入後需輸入 Email / SMS 一次性驗證碼
  • 忘記密碼、註冊連結

3. 註冊頁

功能流程：輸入 Email → 寄送驗證碼 → 驗證通過 → 設定密碼 → 填寫基本資料 → 選擇身分（買家 / 賣家）→ 完成註冊自動登入。

  • Email 驗證碼註冊（5 分鐘內有效）
  • 密碼強度規則（至少 8 碼、需含英數）
  • 基本資料：姓名、暱稱、手機
  • 身分選擇：買家 / 賣家（可同時具備，影響後續是否強制 KYC）
  • 唯一性檢查：Email、手機
  • 同意服務條款與隱私權政策

4. 忘記密碼頁

功能流程：輸入 Email → 寄送重設連結 → 點擊信件連結 → 重設新密碼 → 導回登入頁。

  • 輸入 Email 發送重設連結
  • 重設密碼頁需輸入新密碼、確認新密碼
  • 第三方登入會員不適用此流程

5. 會員中心 / 個人設定

功能說明：會員個人資料、帳號安全、身分驗證、通知、訂閱與消費紀錄集中頁；賣家 / 創作者另提供撥款帳戶設定。

  • 個人資料編輯：姓名、暱稱、頭像、封面圖、自介、聯絡資訊
  • 帳號安全:變更密碼、雙重驗證啟用 / 關閉（可選 Email 或 SMS 作為驗證管道）
  • 實名審核（KYC）入口：身分證正反面上傳、自拍照上傳、狀態顯示（未提交 / 審核中 / 已通過 / 已退回，退回會顯示退回原因）
  • 撥款帳戶設定（賣家 / 創作者專屬）：銀行代號、分行、帳戶名稱、帳號、身分證字號，用於平台每月結算後撥款匯入；編輯時需雙重驗證
  • 收件地址管理：多筆地址新增 / 編輯 / 刪除、設為預設
  • 我的訂閱：訂閱中的創作者、到期日、續訂設定、取消訂閱
  • 我的訂單（買家視角）、我的銷售（賣家視角）
  • 我的拍賣出價與得標紀錄
  • 我的收藏 / 書籤貼文
  • 通知設定：各類事件是否接收 Email / 站內通知

6. 創作者公開頁

功能說明：每位賣家 / 創作者的公開頁，依可見性層級呈現貼文、商品、拍賣與訂閱方案。

  • 個人資訊區：頭像、封面、名稱、自介、追蹤人數、訂閱人數
  • 操作按鈕：追蹤、訂閱方案、打賞、私訊、檢舉
  • 分頁：貼文 / 商品 / 進行中拍賣 / 訂閱方案
  • 可見性控管：
  • 公開貼文所有人可見
  • 僅訂閱者可見：未訂閱者顯示遮罩與訂閱引導
  • 特定方案訂閱者可見：未對應方案顯示升級引導
  • 付費解鎖貼文：顯示解鎖金額與付款按鈕

7. 動態頁（Feed）

功能說明：會員首頁動態流，顯示已追蹤與已訂閱創作者的貼文。

  • 排序切換：最新 / 熱門
  • 貼文三種類型共同呈現：一般貼文 / 商品貼文 / 拍賣貼文
  • 互動動作：按讚、推薦、收藏、留言、轉發（引用轉發）
  • 留言串支援多層回覆、按讚
  • 付費解鎖貼文：顯示解鎖金額，點擊後走付款流程解鎖
  • 依可見性自動過濾使用者未具權限的貼文

8. 發文頁（創作者 / 賣家使用）

功能說明：創作者建立貼文入口，支援三種貼文類型，可設定可見性層級與付費解鎖。

  • 選擇貼文類型：一般 / 商品 / 拍賣
  • 共同欄位：文字內容、圖片（多張）、影片、hashtag、地點
  • 商品貼文：綁定商品、售價、庫存、物流方式、付款方式
  • 拍賣貼文：綁定拍賣商品（欄位見拍賣建立頁）
  • 可見性設定：公開 / 僅訂閱者 / 特定方案訂閱者 / 付費解鎖（設定解鎖金額）
  • 草稿儲存、排程發布
  • 已發布貼文可編輯部分欄位（拍賣貼文上架後限制較多）
  • 刪除貼文（軟刪除，後台仍可檢視）

9. 拍賣建立 / 編輯頁（賣家）

功能流程：賣家建立拍賣商品 → 設定起標價、每次最低加價、起標結標時間 → 上架 → 開始競標。

  • 商品資訊：標題、描述、圖片（多張）、類別、tag
  • 起標價、每次最低加價金額
  • 起標時間、結標時間
  • 物流設定：運費、配送方式（依平台支援物流方式選擇）
  • 付款方式：走平台金流
  • 上架審核開關（由後台設定是否需人工審核後才公開）
  • 上架後限制：不可修改起標價、最低加價、結標時間；僅能修改說明文字與圖片
  • 賣家可於結標前手動下架（需填寫原因，已有出價者通知退出）

10. 拍賣詳情頁（即時競標）

功能流程：買家進入拍賣 → 即時顯示目前最高價 → 出價（需高於目前最高價 + 最低加價）→ 出價成功即時廣播給所有在場買家 → 結標時間到系統自動結標 → 出價最高者為得標者 → 自動建立訂單通知付款。

  • 商品資訊、圖片輪播、賣家連結至創作者主頁
  • 即時倒數計時（至結標時間）
  • 目前最高價、目前領先者暱稱（可設定遮罩）
  • 出價歷史紀錄（時間、金額、出價者暱稱）
  • 出價輸入框（自動預填最低可出價金額 = 目前最高價 + 最低加價）
  • 出價檢核：
  • 未登入 / 未完成 KYC 不可出價（視後台設定）
  • 賣家不可對自己的拍賣出價
  • 出價必須 ≥ 目前最高價 + 最低加價
  • 結標時間後不可再出價
  • 即時推播：最新出價、被超越、快結標、結標通知（無需重新整理）
  • 結標後自動轉態顯示「已結標，得標者：XXX」，系統自動建立訂單並通知得標者付款
  • 分享連結、追蹤拍賣（有通知訂閱機制）
  • 檢舉拍賣入口

11. 商品詳情頁

功能說明：商品貼文對應的商品購買頁。

  • 商品資訊：標題、描述、圖片、規格選項（如顏色、尺寸）
  • 庫存顯示、價格
  • 選擇數量與規格
  • 加入購物車 / 直接購買
  • 買家評價區
  • 賣家資訊區塊（連結至創作者主頁）
  • 分享、檢舉

12. 購物車與結帳流程

功能流程：商品加入購物車 → 結帳頁選擇配送地址、配送方式、付款方式、填寫發票 → 送出訂單 → 導向平台金流付款頁（款項統一收至平台收款帳戶，非直接給賣家）→ 付款結果返回 → 顯示訂單完成頁。平台抽成於月結時自動扣抵。

  • 購物車列表：跨多賣家商品依賣家分組、可調整數量、刪除商品
  • 結帳頁：
  • 配送地址選擇（可新增 / 編輯）
  • 配送方式選擇（依賣家啟用的物流方式）
  • 付款方式選擇（依平台啟用方式：信用卡、ATM、超商代收等）
  • 折扣碼 / 優惠券輸入
  • 發票資訊：個人（二聯）、公司（三聯、統編）、捐贈
  • 訂單備註
  • 金額明細顯示：商品金額、運費、優惠券折抵、應付總額（買家端僅顯示付款總額，不顯示平台抽成）
  • 送出訂單：鎖定庫存並導向金流付款頁（款項進入平台統一收款帳戶）
  • 付款成功 / 失敗返回頁
  • 訂單完成頁：訂單編號、明細、付款方式、配送資訊

13. 訂單列表 / 訂單詳情頁

功能流程：訂單狀態流轉「待付款 → 已付款 → 備貨中 → 已出貨 → 已送達 → 已完成」，或「已取消 / 退款中 / 已退款 / 爭議中」。物流顯示送達後啟動自動完成倒數（系統設定天數，預設 7 天），期間買家可手動確認收貨或發起爭議；逾期未爭議則系統自動轉「已完成」並進入月結。賣家端另顯示平台抽成與淨收款金額。

  • 列表頁搜尋區塊：訂單編號、狀態、訂單時間區間
  • 列表欄位：訂單編號、購買日期、對方（買家看到賣家、賣家看到買家）、金額、狀態、自動完成倒數、操作
  • 詳情頁（買家視角）：
  • 訂單商品明細、金額計算
  • 付款資訊：付款方式、付款時間、付款總額
  • 物流資訊：物流方式、追蹤號、物流事件時間軸
  • 自動完成倒數提示：物流送達後 N 天未爭議自動完成（顯示剩餘天數）
  • 發票資訊
  • 操作（依狀態）：取消（僅未付款）、繼續付款、確認收貨、申請退款、發起爭議
  • 詳情頁（賣家視角）：
  • 訂單商品明細
  • 金額拆解：買家付款總額、金流手續費、平台抽成、賣家淨收款（此筆將於月結財報彙整撥款）
  • 物流資訊、發票資訊
  • 操作（依狀態）：確認訂單、建立出貨（輸入物流單號、選擇物流方式）、標示已出貨、處理退款、回應爭議
  • 訂單訊息紀錄（買賣雙方溝通）

14. 爭議處理頁（買家發起）

功能流程：物流送達後 7 天內，買家可由訂單詳情發起爭議 → 選擇爭議類型、上傳佐證照片 → 系統通知賣家 → 賣家於設定時限內回應（文字說明、補充照片、提出處理方式：同意退款 / 退換貨 / 駁回 / 自定方案）→ 雙方於系統內協商達成共識並結案；無共識則由平台客服介入仲裁 → 仲裁決議（退款 / 退換貨 / 駁回）→ 結案。

  • 爭議申請入口：訂單詳情頁（限「已送達」訂單，且須於物流送達後 7 天內提出）
  • 爭議類型選單：物品瑕疵、與商品描述不符、退換貨需求、未收到貨、其他（自填）
  • 文字說明、佐證照片上傳（多張）
  • 賣家回應介面：文字說明、補充照片、提出處理方式（同意退款 / 退換貨 / 駁回 / 自定方案）
  • 雙方訊息往來紀錄
  • 爭議進度顯示：爭議中 / 等待賣家回應 / 協商中 / 平台仲裁中 / 已結案
  • 雙方達成共識可任一方按「結案」，系統依協議執行（退款 / 退貨 / 結束）
  • 無共識可申請平台介入仲裁
  • （仲裁時效、退款金額分擔規則、線下寄送爭議認證機制：待確認後補充）

15. 私訊（DM）

功能說明：買賣家 / 創作者與粉絲的一對一私訊，支援付費解鎖訊息與打賞。

  • 對話列表、搜尋對話、未讀計數
  • 對話視窗：文字、圖片、影片訊息傳送
  • 即時推播接收新訊息
  • 創作者可發送「付費解鎖訊息」，接收方需付款解鎖後才可檢視內容
  • 對話內打賞（自訂金額或快選金額）
  • 封鎖 / 解除封鎖、檢舉對方

16. 訂閱與打賞流程

功能流程：買家瀏覽創作者訂閱方案 → 選擇方案 → 付款（款項進入平台統一收款帳戶）→ 成為訂閱者，取得對應可見性內容權限。續訂以綁定信用卡自動扣款；可手動取消，到期後失效。訂閱、打賞收入皆於月結時彙整並扣抵平台抽成後撥款給創作者。

  • 訂閱方案列表（方案名稱、月費 / 季費 / 年費、方案說明、包含權益）
  • 訂閱付款（綁卡自動續訂）
  • 續訂 / 取消訂閱管理
  • 訂閱到期前提醒通知
  • 打賞入口：創作者主頁、貼文、私訊；支援自訂金額或快選金額

17. 搜尋結果頁

功能說明：全站搜尋入口，支援多類別搜尋。

  • 搜尋條件：關鍵字、分頁切換（創作者 / 貼文 / 商品 / 拍賣 / hashtag）
  • 各分頁篩選條件（例：拍賣可依狀態篩選、商品可依價格區間）
  • 熱門 hashtag 推薦

18. 通知中心

功能說明：集中檢視平台各類通知。

  • 分類篩選：訂單、拍賣、訂閱、私訊、系統公告
  • 未讀計數、點擊通知轉跳對應頁面
  • 一鍵標示已讀、清空已讀通知

19. 靜態頁與網站結構

功能說明：平台全站共用版型與靜態內容頁。

  • Header：Logo、搜尋框、通知鈴鐺、訊息、會員選單、購物車
  • Footer：平台說明、條款、隱私權政策、常見問題、客服連結、社群連結
  • RWD 響應式設計（桌機 / 平板 / 手機）
  • 服務條款、隱私權政策、常見問題、關於我們等靜態頁（內容由後台維護）

  • 登出 API
  • 忘記密碼 / 重設密碼 API
  • 雙重驗證啟用 / 關閉 API

  • 留言串取得 / 建立 / 刪除 API

  • 審核備註欄位

  • 審核通過自動更新該會員身分驗證狀態為「已通過」

  • 手動回補物流事件（特殊情況）
  • （線下寄送認證機制具體欄位與流程：待下次會議確認後補充）

13. 爭議處理

功能流程：買家於物流送達後 7 天內發起爭議 → 賣家收到通知並回應（文字、補充照片、處理方式）→ 雙方於系統內協商；達成共識結案，否則平台客服介入仲裁 → 仲裁決議（退款 / 退換貨 / 駁回）→ 結案；涉及已撥款月結款項時連動調整下期撥款。所有訂單紀錄、付款紀錄、物流狀態、商品頁描述快照、雙方對話與上傳證明皆完整保留作為判斷依據。

  • 搜尋區塊：爭議編號、訂單編號、雙方、狀態、建立時間、爭議類型

  • 詳情頁完整證據總覽：
  • 訂單資訊（含商品頁描述快照、商品圖快照）
  • 付款紀錄、金流交易明細
  • 物流狀態與物流事件時間軸
  • 買家爭議陳述、爭議類型、佐證照片
  • 賣家回應、補充照片、提出之處理方式
  • 雙方訊息往來完整紀錄
  • 客服處理訊息與內部備註
  • 客服仲裁決議：退款（全額 / 部分）、駁回（維持訂單）、要求退換貨、結案
  • 決議後自動執行對應動作（退款執行、訂單狀態更新、通知雙方）
  • 已進入月結之款項連動調整（前期已撥款者於下期月結沖銷）
  • 紀錄保留：所有訂單與爭議資料於結案後保留至少 N 年（保留期限由系統設定）
  • （仲裁時效、退款金額分擔規則、線下寄送爭議認證機制：待下次會議確認後補充）

15. 分潤管理 / 月結財報

功能流程：平台採「統一收款 → 月結撥款」模式，所有買家款項（訂單、訂閱、打賞、付費解鎖）先匯入平台統一收款帳戶；系統於每月結算日自動彙總各創作者當月交易明細，扣除退款、金流手續費、平台抽成後產出月結財報 → 後台人員確認 → 由財務人工匯款至創作者撥款帳戶 → 後台標示已撥款 → 系統寄發通知給創作者。

  • 搜尋區塊：結算月份、創作者、撥款狀態、撥款日期
  • 列表欄位：結算月份、創作者、總收入、退款、金流手續費、平台抽成、可撥款金額、撥款狀態、撥款日期、操作
  • 財報詳情：
  • 該月份所有交易明細（分類統計：訂閱 / 商品 / 拍賣 / 打賞 / 付費解鎖）
  • 退款明細
  • 金流手續費計算、平台抽成計算、淨可撥款金額
  • 跨月調整項目（前月爭議結案退款、前月退款等影響）
  • 匯出單月財報（Excel）
  • 匯出多月度總表（Excel）
  • 標示已撥款：輸入匯款日期、匯款參考編號、附件（轉帳憑證），系統寄發通知給創作者
  • 撤回已撥款標記（權限控管，記錄原因）
  • 手動觸發重新結算（異常狀況使用）
